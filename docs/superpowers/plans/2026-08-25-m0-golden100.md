# M0 Golden100 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Compiler Golden 从 20 个扩展为 100 个，并保持每项真实 V0–V6 通过。

**Architecture:** 复用现有 fixture 目录协议与端到端测试；新增 80 个静态 JSON fixture，并以测试发现、布局计数、canonical epJSON hash、对象摘要和真实 EnergyPlus 设计日仿真共同冻结行为。

**Tech Stack:** Python 3.11、unittest、Pydantic v2、EnergyPlus v23.1。

**Spec:** `docs/superpowers/specs/2026-08-25-m0-golden100-design.md`

## Global Constraints

- EnergyPlus 固定 v23.1；每项 V5 在独占目录运行设计日，Severe=0、Fatal=0。
- 不提交 IDF、运行时产物或数据 manifest；每个 Golden 使用独立目录。
- 不扩展真实 AirLoopHVAC、PlantLoop 或 Compiler 支持域。
