# M0-016 Compiler Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 冻结 Spec-LoRA 与 IDF 工件隔离边界，并为 Compiler 增加可执行的 round-trip、metamorphic、mutation 稳定性证据。

**Architecture:** 新测试放在一个集成模块中，复用既有 `compile_scenario`、`validate_artifact`、`canonical_epjson_bytes` 和 V3/V4 Validator，不修改 Compiler 支持域。生产 LoRA 边界由 ADR-0001 和 M1 文档固定，测试工件只存在临时目录。

**Tech Stack:** Python 3.11、unittest、Pydantic v2、EnergyPlus v23.1、uv。

**Spec:** `docs/superpowers/specs/2026-08-25-m0-016-stability-design.md`

## Global Constraints

- EnergyPlus 固定 v23.1；所有外部转换在 `TemporaryDirectory` 运行。
- Compiler 唯一输入保持为 `ResolvedScenarioSpec`；不实现真实 AirLoopHVAC 或 PlantLoop。
- 生产 `spec_sft` 不得含任何 IDF/epJSON 文件字段；Direct 路线保持隔离。
- 不提交 IDF、epJSON、仿真输出或运行时产物。
