## 5. 警告与解释

- uv 缓存和 `.venv` 位于不同文件系统时无法 hardlink，自动退回复制；影响安装速度，不影响正确性；
- 沙箱不允许写用户级 Matplotlib cache，因此导入时出现 cache warning；常规本地终端不影响服务功能；
- `uv run` 在受限沙箱中访问用户 uv cache 可能被拒绝，本次使用 `.venv` Python 独立验证环境；
- 当前 `.env` 原本为空，本任务只写入公开安装路径，没有覆盖密钥。
