## 3. 关键实现

- 目录移动前验证源和目标绝对路径均位于当前 worktree 的 `data` 下，且目标不存在；
- 移动前后按相对路径比较 68 个 IDF 的 SHA-256，不匹配为 0；
- README 只解释 folder，不逐个叙述 68 个文件，也不复制 manifest；
- manifest 的 `copied_relative_path` 本来就是 `idf/...` 内部相对路径，因此无需修改 schema 或记录；
- 首次暂存时发现旧 `.gitattributes` 只匹配旧目录，导致 Git clean filter 把官方 CRLF 规范化为 LF；新增真实 `git hash-object` 回归测试后迁移 `-text` 规则，并将检查扩大到 68 个 IDF 与许可证，最终 68/68 迁移前 Git blob 与新路径 index blob 完全相同，累计 diff 为 100% rename；
- `geometry_references` 继续明确隔离，不作为正向 SFT 标签。
